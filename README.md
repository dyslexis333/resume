# Портфолио-резюме

Одностраничный сайт Максима Грибинюка для поиска стажировки или первой работы в разработке, цифровом контенте и DevOps.

## Структура

- `index.html` — семантическая разметка: главная секция, информация о себе, навыки, опыт, интересы, контакты и footer.
- `style.css` — мобильные базовые стили, Grid/Flexbox и адаптивные desktop-правила.
- `theme-overrides.css` — палитра светлой темы.
- `script.js` — мобильное меню, переключение тем, смена фотографии и сохранение темы.
- `assets/` — предоставленные фотографии.
- `server.cjs` — простой локальный сервер для проверки сайта.

## Технологии и данные

Использованы HTML5, CSS3 и чистый JavaScript. В проекте нет выдуманных проектов, коммерческого опыта, сертификатов или неподтверждённых контактов. Указаны реальные данные об образовании, интересах, спортивном разряде и ссылки на Telegram, VK и FACEIT.

## AI и проверка

В работе использовались ChatGPT и Codex для исследования, прототипирования, реализации и ревью. Существенный запрос: «Создай одностраничное портфолио-резюме с адаптивной строгой визуальной системой, переключением тем и интерактивной навигацией». Самостоятельно проверены структура HTML, адаптивность, относительные пути к изображениям, клавиатурная навигация и работа JavaScript.

## Запуск

```bash

```

Откройте `http://127.0.0.1:4174`.
